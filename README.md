# Figures for the enrichment + UMAP use case

Figures generated by `examples/scRNAseq_enrichment` on **pbmc4k** from the
Bioconductor package
[TENxPBMCData](https://bioconductor.org/packages/TENxPBMCData/)
(4,340 cells, 4,336 after QC, 13 Leiden clusters).

The counts come from the R version of this example, which fetches pbmc4k and
writes it out in 10x format; both languages then start from that one directory,
which is what makes their numbers comparable.

This branch only holds images, so the feature branch stays free of binaries.
